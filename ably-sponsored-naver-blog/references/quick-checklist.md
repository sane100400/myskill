# 에이블리 체험단 글 작성용 AI 실행 카드

아래 규칙만 우선 적용해 원고를 작성한다.

1. 현재 사용자 지시와 미션 필수사항이 최우선이다.
2. 상품별로 근거를 `실사용 / 사진 관찰 / 공식 정보 / 기대` 중 하나 이상으로 구분한다.
3. 실제로 하지 않은 구매·사용·방문·클릭·장바구니·시식·취향을 만들지 않는다.
4. 같은 상품에서 실제 경험과 기대 표현을 섞지 않는다.
5. 맛·착용감·지속력·성능·효과는 직접 확인한 범위에서만 확정한다.
6. 제목은 주제와 차별점이 보이게 쓰고 같은 키워드를 반복하지 않는다.
7. 도입은 2~4문장으로 실제 계기나 선택 기준부터 말한다. 범용 날씨·고민·인사말은 생략한다.
8. 상품 문단은 `구체적인 특징 → 고른 이유·사용 장면·실제 결과` 중 근거 있는 두 요소로 쓴다.
9. 한 문단은 한 가지 이야기만 담고 1~3문장으로 끝낸다. 문장 길이와 종결어미를 자연스럽게 섞는다.
10. 화면을 중계하거나 상품명을 첫 문장에서 반복하지 않는다.
11. `핵심 포인트·가장 큰 장점·활용도·합리적·추천드립니다` 같은 추상어 대신 수치·형태·상황을 쓴다.
12. 모든 상품을 같은 틀로 쓰거나 장단점을 억지로 한 세트로 만들지 않는다.
13. 과장, 근거 없는 효능, 반복 CTA를 쓰지 않는다. 링크·구매 유도는 전체에서 한 번이면 충분하다.
14. 실제 후기의 확인된 불편은 조건과 범위를 붙여 구체적으로 쓸 수 있다.
15. 경제적 이해관계는 미션의 정확한 문구와 위치를 따르고, 별도 지시가 없으면 제목 또는 첫 부분에서 관계의 성격을 명확히 밝힌다.
16. 완성 후 경험 수준, 표시 문구, 키워드, 상품명, 수치, 이미지, 개인 링크, 줄바꿈을 원자료와 대조한다.
