# 에이블리 수익성 네이버 블로그 문체 가이드

개정일: 2026-09-02

이 문서는 에이블리 크리에이터 링크, 수익성 링크, 제품·서비스 제공 또는 원고료가 포함된 네이버 블로그 글에 적용한다. 목표는 광고 문장을 구어체로 꾸미는 것이 아니라, **확인된 사실을 작성자의 실제 관심·경험과 구체적으로 연결해 평소 블로그 글처럼 쓰는 것**이다.

## 1. 적용 우선순위

1. 현재 요청에서 사용자가 직접 준 지시와 수정 피드백
2. 미션 가이드의 필수 사실·키워드·이미지·링크·표시 문구
3. 이 문서의 문체 규칙
4. 공개 참고 글에서 확인한 일반적인 경향

상위 지시와 충돌하면 아래 규칙을 기계적으로 적용하지 않는다. 참고 글의 문장, 도입 소재, 상품 순서, 감탄사, 오탈자를 복제하지 않는다.

## 2. 작성 전: 글 유형과 근거 확인

글 전체의 주 유형을 정하고, 상품별 근거 수준은 따로 구분한다.

- **실사용·실구매 후기:** 실제 사용 과정, 조건, 체감, 비교, 확인된 아쉬움을 쓸 수 있다.
- **미사용 큐레이션·행사 소개:** 선택 이유, 보이는 특징, 공식 정보, 사용 장면에 대한 기대만 쓴다.
- **방문·서비스 체험:** 방문 계기와 실제 동선, 대기, 응대, 이용 결과를 중심에 둔다.
- **혜택·기획전 안내:** 기간·쿠폰 등 필수 정보만 정리하고 작성자가 고른 상품으로 빠르게 넘어간다.

자료가 부족하면 경험이나 취향을 만들어 보충하지 않는다. 같은 상품에서 `먹어봤다`와 `먹어보고 싶다`, `입어봤다`와 `입기 좋겠다`를 섞지 않는다.

## 3. 사실과 표현의 경계

| 근거 | 쓸 수 있는 내용 | 쓰면 안 되는 내용 |
|---|---|---|
| 사용자가 실제 구매·사용·방문했다고 확인 | 실제 행동, 조건, 체감, 비교, 재사용 이유 | 말하지 않은 기간·횟수·효과·에피소드 |
| 사용자 사진·상품 이미지 | 보이는 색, 형태, 구성, 양, 길이, 디테일 | 맛, 착용감, 내구성, 성능, 체형·피부 개선 단정 |
| 공식 상세 페이지·미션 자료 | 수치, 소재, 구성, 기간, 가격, 배송, 공식 기능 | 출처에 없는 품질·효능·인기·최상급 주장 |
| 확인된 취향이나 합리적인 기대 | `평소 ○○를 좋아해 골랐다`, `○○와 입어보고 싶다` | 구매·클릭·장바구니·시식 등 하지 않은 행동 |

필요할 때 근거를 문장에 드러낸다. `직접 써보니`, `사진상`, `상세에는`, `~해보고 싶다`를 구분해 쓴다.

- 음식은 먹었을 때만 맛·식감·양을 확정한다. 사진만 있으면 단면·재료·크기와 기대를 말한다.
- 패션·뷰티는 직접 입거나 발랐을 때만 착용감·발림·지속력·변화를 말한다.
- 생활용품·IT는 직접 확인하거나 측정한 범위에서만 성능을 평가하고, 나머지는 공식 사양으로 밝힌다.

## 4. 글의 기본 구조

### 제목

`검색 주제 + 상품·행사명 + 실제로 다룬 차별점 하나` 정도로 만든다. 같은 뜻의 키워드를 줄줄이 붙이지 않는다. `내돈내산`, `재구매`, `N일 사용`, `솔직 후기`는 사실일 때만 쓴다.

### 도입

2~4문장 안에 **왜 이 글을 쓰는지 또는 무엇을 기준으로 볼지** 제시한다.

- 후기: 쓰게 된 계기 → 실제 사용 상황
- 행사·큐레이션: 실제 관심사나 선택 기준 → 행사가 관련 있는 이유

억지 날씨 이야기, 가상의 고민, `많은 분들이 궁금해하시는데요`, `오늘은 자세히 알아보겠습니다` 같은 범용 도입은 생략한다.

### 본문

- 행사형: 생활 맥락 → 필수 혜택 → 개인 링크 → 고른 상품
- 후기형: 사용 전 상황 → 실제 사용 과정 → 구체적인 체감과 조건 → 맞는 사용 상황
- 상품별 블록: `브랜드명 + 상품명` 소제목 → 관련 이미지 → 1~2개 짧은 문단 → 개인 링크

상품 하나에는 아래 세 요소 중 **근거가 있는 두 가지만** 넣어도 충분하다.

1. 사진이나 실제 사용에서 확인한 특징
2. 그 상품을 고른 실제 이유
3. 입는 때·먹는 때·사용하는 장면 또는 실제 결과

소제목에 상품명이 있으면 첫 문장에서 다시 소개하지 않는다. 문단은 대체로 `구체적인 특징 → 내 생활에서의 의미`로 이어간다.

### 마무리

핵심 인상이나 다시 볼 상품을 한 번만 정리한다. 링크 확인이나 구매 유도 문장은 글 전체에서 한 번이면 충분하다.

## 5. 자연스러운 한국 블로그 말투

- `~인데요`, `~더라고요`, `~거든요`, `~하려고요`는 의미에 맞게 쓰되 종결어미를 규칙적으로 돌려 쓰지 않는다.
- 한 문단에는 한 가지 이야기만 담고 1~3문장으로 끝낸다. 짧은 문장과 긴 문장을 섞는다.
- 추상적인 칭찬보다 명사·수치·상황을 쓴다. `활용도가 높다`보다 무엇과 언제 쓰기 좋은지 말한다.
- 사진이나 화면을 중계하지 않는다. `열어보니`, `스크롤을 내리니`, `사진을 보시면` 대신 새로 알 수 있는 내용을 바로 쓴다.
- 실제 후기에서는 확인된 불편이나 조건을 숨기지 않아도 된다. 단점을 일부러 만들지 말고 `내 기준에는 소매가 길었다`처럼 범위를 분명히 한다.
- 이모지·느낌표·줄바꿈은 사용자의 기존 말투와 현재 요청을 우선한다. 별도 지시가 없으면 소량만 쓴다.

## 6. AI 티가 강해지는 패턴

아래 패턴이 보이면 삭제하거나 구체적인 근거로 바꾼다.

- **가짜 생활 서사:** 하지 않은 고민, 구매, 장바구니, 배송 대기, 반복 사용을 만든다.
- **범용 광고어:** `핵심 포인트`, `가장 큰 장점`, `전반적으로`, `완성도가 높다`, `합리적인 선택`, `추천드립니다`만으로 평가한다.
- **복제형 문단:** 모든 상품을 `첫인상 → 장점 3개 → 추천 대상 → CTA`로 반복한다.
- **과장과 판정:** `역대급`, `무조건`, `맛이 없을 수 없다`, `인생템`, `최고`, `완벽`을 근거 없이 쓴다.
- **근거 없는 효능:** 성분·소재·재료만 보고 건강, 다이어트, 피부 개선, 체형 보정, 안전성을 단정한다.
- **억지 균형:** 신뢰를 주려고 확인하지 않은 단점을 넣거나 모든 후기마다 장단점을 한 세트로 만든다.
- **반복 CTA:** `꼭 사세요`, `절대 놓치지 마세요`, `지금 바로 확인하세요`를 상품마다 붙인다.

고칠 때는 추상어를 다른 추상어로 바꾸지 말고 조건을 추가한다.

- `활용도가 높은 아이템이에요` → 실제로 함께 입을 옷이나 사용할 상황을 쓴다.
- `아쉬운 부분도 있었어요` → 무엇이, 어떤 조건에서, 누구에게 불편할 수 있는지 쓴다.

## 7. 필수 준수 사항

- 경제적 이해관계는 미션에서 요구한 정확한 문구와 위치로 표시한다. 별도 지시가 없으면 제목 또는 본문 첫 부분에서 제공 주체와 제품 제공·원고료·판매 수수료 등 **경제적 관계의 성격**을 명확히 밝힌다.
- `일정 수수료를 받을 수도 있다`처럼 광고 관계 자체가 불분명해지는 문구는 임의로 만들지 않는다.
- 필수 키워드는 지정된 형태와 횟수만 지키고 검색 노출을 위해 추가 반복하지 않는다.
- 다른 사람의 링크나 가이드 링크가 아니라 사용자의 개인 리워드 링크만 넣는다.
- 상품명, 가격, 기간, 할인율, 수치, 이미지, 링크를 원자료와 대조한다.
- 문체를 다듬은 뒤에도 사실·수치·표시 문구를 바꾸지 않는다.

## 8. 최종 점검

1. 같은 상품의 경험 수준과 시제가 끝까지 일치하는가?
2. 표시 문구, 필수 키워드, 개인 링크가 정확한가?
3. 맛·착용감·효과·행동마다 확인 가능한 근거가 있는가?
4. 도입이 실제 맥락이나 선택 기준으로 시작하는가?
5. 상품마다 구체적인 특징이 생활 장면이나 실제 결과로 이어지는가?
6. 앞뒤 문단이 같은 틀·종결어미·CTA를 반복하지 않는가?
7. 가짜 경험, 과장, 근거 없는 효능, 억지 단점이 남아 있지 않은가?
8. 이미지·수치·기간·링크·줄바꿈이 현재 미션 지시와 맞는가?
