# 문체 예시: 같은 틀을 반복하지 않는 리뷰

이 예시는 문장을 복사하는 템플릿이 아니다. **사용자 메모를 얼마나 남기고, 경험에 따라 글 모양이 얼마나 달라질 수 있는지**만 참고한다.

## 1. 가전 — 아쉬움부터 시작

### 사용자 메모

```text
책상 옆에서 이틀 써봄. 물 넣는 입구 넓어서 닦기 편함.
완전 무소음은 아닌데 낮에는 별로 신경 안 쓰임.
밤에는 소리에 예민하면 들릴 듯.
```

### 완성 예시

```text
완전 무소음은 아니에요. 낮에 책상 옆에 두고 쓸 때는 거의 신경 안 쓰였는데, 밤에 조용한 방에서는 작동음이 조금 들렸습니다. 소리에 예민한 분이면 침대 바로 옆보다는 거리를 두는 게 나을 것 같아요.

대신 물 넣는 입구가 넓어서 이틀 쓰고 닦아봤을 때 세척은 편했어요. 손이 들어가니까 구석 닦느라 씨름할 일이 없었던 점은 좋았습니다.
```

## 2. 냉동식품 — 조리 장면 하나로 충분한 경우

### 사용자 메모

```text
또띠아 두껍고 밀가루맛 난다는 후기 보고 걱정함.
에프 180도 13분 돌렸는데 겉 바삭하고 치즈맛 많이 남.
토마토 스파게티랑 피자 사이 맛. 나는 극호.
```

### 완성 예시

```text
또띠아가 두껍다는 얘기가 있어서 살짝 걱정했는데 저는 에어프라이어에 180도 13분 돌려 먹으니 겉이 바삭해져서 괜찮았어요. 전자레인지로만 데웠으면 느낌이 좀 달랐을 것 같긴 합니다.

맛은 토마토 스파게티랑 피자 사이쯤? 치즈맛이 꽤 진하게 나서 저는 완전 극호였어요. 이런 익숙한 피자맛 좋아하면 간식으로 먹기 괜찮습니다.
```

## 3. 신발 — 사이즈 판단이 중심인 후기

### 사용자 메모

```text
평소 245, 발볼 넓음. 250 삼.
앞은 약간 남는데 발볼은 안 끼어서 편함. 얇은 양말이면 뒤꿈치 살짝 뜸.
두꺼운 양말 신으면 괜찮았음.
```

### 완성 예시

```text
평소 245를 신는데 발볼이 넓어서 250으로 골랐어요. 앞쪽은 조금 남지만 발볼이 끼지 않아서 저는 이 사이즈가 더 편했습니다.

얇은 양말을 신으면 뒤꿈치가 살짝 뜨고, 도톰한 양말이랑 신었을 때는 괜찮았어요. 발볼 때문에 반 사이즈 올릴 분들은 양말 두께도 같이 생각하면 될 것 같아요.
```

## 4. 생활용품 — 완성도보다 용도가 중요한 후기

### 사용자 메모

```text
가게 자리가 좁아서 책상 옆에 붙여씀.
접착은 잘됨. 엄청 튼튼한 건 아니고 무거우면 옆이 찢어짐.
나는 하루이틀 쓰고 버리는 용도라 별 문제 없었음.
```

### 완성 예시

```text
가게 자리가 좁아서 쓰레기통 대신 책상 옆에 붙여서 쓰고 있어요. 접착은 생각보다 잘 되고, 떼었을 때 바닥으로 툭 떨어진 적도 아직은 없었습니다.

봉투 자체가 엄청 튼튼한 편은 아니라 무거운 걸 많이 넣으면 옆이 찢어져 내려와요. 저는 하루이틀 쓰고 바로 버리는 용도로 산 거라 크게 불편하지 않았고, 가벼운 영수증이나 포장지 모아두기에는 딱이었습니다.
```

## 5. 반려동물용품 — 선택 실수가 후기의 중심인 경우

### 사용자 메모

```text
대형이라는 말만 보고 샀는데 성묘한테 작았음. 내 실수.
색은 아이보리보다 베이지에 가까움. 가볍고 손잡이는 편함.
화장실로 못 써서 쿠션 넣어 쉼터로 쓰는 중인데 잘 들어감.
```

### 완성 예시

```text
저는 상세 사이즈를 제대로 안 보고 ‘대형’이라는 말만 보고 골랐는데 성묘가 쓰기에는 작았어요. 이건 제품 문제라기보다 제 선택 실수라, 성묘용으로 보는 분은 치수를 꼭 확인하는 게 좋겠습니다.

색도 이름은 아이보리지만 실제로는 베이지에 더 가까웠어요. 화장실로는 못 쓰게 돼서 쿠션을 넣어줬는데 의외로 고양이가 잘 들어가서 지금은 쉼터가 됐습니다ㅎㅎ 가볍고 양쪽 손잡이가 있어서 옮기기는 편해요.
```

## 6. 화장품 — 사용 부위와 양만 말하는 후기

### 사용자 메모

```text
복합성. 얼굴 전체 바르면 답답하고 많이 바르면 밀림.
밤에 건조한 볼 쪽만 얇게 바르면 다음날 덜 당김.
향은 거의 못 느낌.
```

### 완성 예시

```text
복합성 피부인데 얼굴 전체에 바르면 저는 조금 답답했어요. 양을 많이 쓰면 다음 제품 바를 때 밀리기도 해서, 지금은 밤에 건조한 볼 쪽에만 얇게 바르고 있습니다.

이렇게 쓰니까 다음 날 아침에 볼이 당기는 느낌은 덜했어요. 향은 거의 느끼지 못했고요. 지성에 가까운 분이라면 처음부터 소량만 써보는 게 나을 것 같습니다.
```

## 7. 유아용품 — 아이 반응이 그대로 흐름이 되는 후기

### 사용자 메모

```text
43개월. 캐릭터 엄청 좋아함.
색칠보다 스티커랑 만들기를 더 좋아함. 색칠은 아직 선 안에 못함.
2권 겉표지는 다른데 색칠 부분은 겹치는 게 있음.
```

### 완성 예시

```text
43개월 아이가 이 캐릭터를 워낙 좋아해서 보자마자 스티커부터 찾았어요. 아직 선 안에 맞춰 색칠하는 건 어려워해서 색칠 페이지보다 스티커 붙이기랑 만들기를 더 오래 가지고 놀았습니다.

두 권이라 내용이 전부 다를 줄 알았는데 겉표지와 스티커는 달라도 색칠 부분은 겹치는 게 조금 있어요. 그래도 아이는 크게 신경 쓰지 않고 좋아했어요. 색칠을 꼼꼼히 하는 아이보다는 캐릭터 자체를 좋아하고 이것저것 만드는 걸 좋아하는 아이에게 더 잘 맞을 듯합니다.
```

## 8. 경험이 적으면 짧게 끝내도 되는 후기

### 사용자 메모

```text
오늘 받아서 한 번만 써봄. 버튼 하나라 쉬움.
크기는 예상보다 작았는데 내 책상에는 오히려 좋음.
내구성은 아직 모름.
```

### 완성 예시

```text
오늘 받아서 한 번만 써봤어요. 버튼이 하나라 설명서를 오래 보지 않아도 바로 쓸 수 있었고, 크기는 생각했던 것보다 작았습니다. 그런데 제 책상에는 자리를 많이 안 차지해서 오히려 이쪽이 더 잘 맞았어요.

아직 한 번 사용한 거라 내구성까지는 모르겠고, 첫 사용 기준으로는 조작이 단순하고 보관하기 편한 점이 가장 좋았습니다.
```

## 이 예시들의 공통점

- 상품의 모든 특징을 다루지 않는다.
- 메모에서 가장 구체적인 부분이 글의 절반 이상을 차지하기도 한다.
- 시작 방식과 끝맺음이 제각각이다.
- 자연스럽게 보이려고 거친 말이나 오탈자를 새로 만들지 않는다.
- 사용자가 제공한 표현이 글의 온도를 결정한다.
