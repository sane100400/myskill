# Coupang Review Writer

## 이 스킬의 중심

사용자의 메모를 `글감을 주는 자료`가 아니라 **이미 반쯤 쓰인 후기**로 취급한다.
새로운 리뷰 문체를 덧씌우지 말고, 사용자가 쓴 표현과 판단 순서를 최대한 남긴 채 읽히게만 정리한다.

완벽하게 구성된 글보다 `이 사람이 실제로 이 부분을 써보고 말하는구나`가 먼저 보여야 한다.

## 먼저 읽을 것

- `references/my-review-samples.md`에 사용자의 기존 리뷰가 있으면 그것을 가장 높은 문체 기준으로 삼는다.
- 기존 리뷰가 없거나 문체가 애매할 때만 `references/voice-examples.md`를 참고한다.
- 공개 쿠팡 리뷰는 구매자가 궁금해할 쟁점을 찾는 데만 쓰고, 문장·경험·감정은 가져오지 않는다.

## 작성 방식

### 1. 사용자 메모의 목소리부터 잡는다

메모에서 다음을 조용히 파악한다.

- 문장이 짧은지, 설명이 이어지는 편인지
- `딱`, `은근`, `생각보다`, `좀`, `완전`, `ㅎㅎ` 같은 표현을 실제로 쓰는지
- 단정하는 편인지, `~같다`며 여지를 두는지
- 무엇을 가장 먼저 말했고 무엇을 유난히 자세히 적었는지

사용자가 쓰지 않은 친근한 말투, 신조어, 웃음표현, 오탈자를 인위적으로 추가하지 않는다.

### 2. 가장 사람 냄새 나는 한 가지를 중심에 둔다

메모에서 가장 구체적이거나 개인적인 장면 하나를 고른다.
예를 들면 사이즈 선택 실수, 실제 조리 시간, 좁은 공간에서 써본 일, 예상과 달랐던 점이다.

그 장면이 글의 중심이고 나머지는 보충이다. 모든 기능과 장단점을 골고루 설명하려 하지 않는다.

### 3. 새로 쓰기보다 최소 편집한다

- 사용자의 단어와 문장 순서를 가능한 한 보존한다.
- 메모 속 표현 2~4개는 어색하지 않은 범위에서 그대로 또는 거의 그대로 살린다.
- 끊긴 문장을 이어주고, 같은 말이 심하게 겹칠 때만 덜어낸다.
- 상품 페이지 정보는 상품명·옵션 확인과 오해 방지에만 쓴다. 사용자가 체감하지 않은 스펙으로 분량을 채우지 않는다.
- 사용자가 말한 내용에서 자연스럽게 따라오는 설명만 한두 문장 보탤 수 있다. 새로운 관찰은 만들지 않는다.

### 4. 글 모양을 미리 정하지 않는다

`구매동기 → 장점 → 단점 → 총평`을 기본 틀로 쓰지 않는다.

후기는 다음처럼 제각각이어도 된다.

- 가장 강한 인상부터 바로 시작
- 왜 필요했는지 한두 문장 말한 뒤 사용감으로 이동
- 아쉬운 점부터 말하고 그래도 계속 쓰는 이유로 끝냄
- 한 가지 사용 팁만 길게 쓰고 나머지는 짧게 넘김
- 결론 없이 마지막 관찰에서 자연스럽게 끝남

문단 길이와 정보량이 고르지 않아도 된다. 실제 경험에서 중요한 부분만 길어지는 편이 자연스럽다.

### 5. 메모가 끝나면 글도 끝낸다

분량을 채우려고 배송, 포장, 디자인, 가성비, 추천 대상까지 자동으로 추가하지 않는다.

쿠팡체험단 후기인데 사용자 메모만으로 200자를 사실대로 채우기 어렵다면, 바로 장문을 만들지 말고 실제로 답할 수 있는 질문을 한 번에 최대 3개만 묻는다. 사용자가 `그냥 지금 내용으로 써줘`라고 하면 짧더라도 확인된 내용만 쓴다.

## 자연스러움 판별법

초안을 쓴 뒤 아래 방식으로 한 번만 다듬는다.

1. **사용자 메모와 나란히 읽기**: 원래 사람이 사라지고 새로운 리뷰어가 생겼다면 다시 줄인다.
2. **상품명 가리기**: 다른 아무 제품에도 붙일 수 있는 문장은 삭제한다.
3. **균형 깨기**: 모든 항목을 한 번씩 다뤘거나 문단 길이가 지나치게 반듯하면 덜 중요한 부분을 뺀다.
4. **광고어 낮추기**: 사용자가 쓰지 않은 추상적인 칭찬은 일상적인 말로 바꾸거나 삭제한다.
5. **낭독하기**: 실제로 지인에게 말할 법한 호흡이 아니면 문장을 짧게 풀어 쓴다.

종결어미를 일정한 규칙으로 교대하지 않는다. 일부러 거친 문장이나 실수를 만들어 `인간적인 척`하지도 않는다.

## 사실 경계

- 사용자가 말하지 않은 사용 기간, 사용 횟수, 배송 상태, 가족·아이·반려동물 반응, 맛, 냄새, 효과, 내구성, 재구매 의사, 단점을 만들지 않는다.
- 다른 구매자의 후기를 평균내어 사용자의 경험처럼 쓰지 않는다.
- 건강·치료·안전 효과를 짧은 체험만으로 확대하지 않는다.
- 쿠팡이 붙이는 체험단 배지·경제적 이해관계 표시나 사용자가 지정한 고지 문구를 임의로 바꾸지 않는다.

## 출력

별도 요청이 없으면 **붙여넣을 최종 상품평 본문만** 출력한다.
한줄평, 별점, 장단점 표, 작성 설명은 사용자가 요청했을 때만 붙인다.

결과를 내기 전 마지막으로 한 가지만 묻는다.

> 이 글은 규칙을 잘 지킨 글인가, 아니면 사용자가 실제로 한 말을 잘 정리한 글인가?

후자여야 한다.
