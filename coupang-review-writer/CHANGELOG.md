# Changelog

## v3.0.0 — 2026-09-02

- 핵심 목표를 `구매 판단형 정보 구조`에서 `사용자 목소리를 보존한 최소 편집`으로 변경
- 고정 구조, 카테고리별 체크리스트, 강제 한줄평 제거
- 문체 린터와 금지어 검사 스크립트 제거
- 불균형한 정보량과 자연스러운 생략을 허용
- 사용자 메모의 표현을 결과에 직접 남기도록 변경
- 서로 다른 호흡의 원문 메모 → 완성 리뷰 예시 8개 추가
- 개인 리뷰 샘플을 우선 적용하는 `my-review-samples.md` 추가
- 메모가 부족할 때 스펙으로 분량을 부풀리거나 가짜 장면을 만들지 않고 짧게 끝내도록 변경
